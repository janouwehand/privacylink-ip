About

PrivacyLink IP is a small, independent, open-source tool with one job: show the public IP addresses this server observes for your connection. No ads, no account, no analytics, no history of who connected.

Both address families get their own row and their own Copy button. The address of the connection that loaded this page is part of the page itself, so it is visible before any script runs.

API

The same answer without a browser: plain text or JSON, no cookies, no key.

curl -sS https://ip.privacylink.nl/api/ip

This hostname answers with whichever family your connection uses. For IPv4 only use https://v4.ip.privacylink.nl/api/ip; for IPv6 only use https://v6.ip.privacylink.nl/api/ip.

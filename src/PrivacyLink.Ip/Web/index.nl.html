Over

PrivacyLink IP is een klein, onafhankelijk opensourcehulpmiddel met één taak: de publieke IP-adressen tonen die deze server voor je verbinding ziet. Geen advertenties, geen account, geen analytics en geen geschiedenis van bezoekers.

Beide adressen krijgen een eigen rij en een eigen kopieerknop. Het adres van de verbinding die deze pagina opende, staat in de pagina zelf en is dus zichtbaar voordat er een script draait.

API

Hetzelfde antwoord zonder browser: platte tekst of JSON, zonder cookies of sleutel.

curl -sS https://ip.privacylink.nl/api/ip

Gebruik https://v4.ip.privacylink.nl/api/ip voor alleen IPv4 en https://v6.ip.privacylink.nl/api/ip voor alleen IPv6.
